# Bài tập Python cơ bản 1

Repo này chứa lời giải cho 10 bài tập Python cơ bản trong file đề bài thực tập.

## Cách chạy

Mở terminal tại thư mục repo, sau đó chạy từng bài:

```powershell
python bai_01_chuan_hoa_ho_ten.py
python bai_02_dao_nguoc_tu.py
python bai_03_ky_tu_nhieu_nhat.py
python bai_04_dem_ky_tu.py
python bai_05_tach_so.py
python bai_06_cat_ho_ten.py
python bai_07_viet_hoa_dau_tu.py
python bai_08_chu_xen_ke.py
python bai_09_chuoi_doi_xung.py
python bai_10_doc_so_3_chu_so.py
```

Các chương trình được viết theo hướng đơn giản, phù hợp với người mới học Python.
